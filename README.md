# FILE-DRP-PASIEN

Repositori ini memuat seluruh data rekam medis pasien, data laboratorium, catatan perkembangan terintegrasi (CPPT), serta analisis lengkap **Pemantauan Terapi Obat (PTO)** dan **Drug Related Problems (DRP)** pada pasien rawat inap Ny. Sunarti di RSPAU dr. S. Hardjolukito.

- **[Laporan Resmi PDF](./LAPORAN_PEMANTAUAN_TERAPI_OBAT_SUNARTI.pdf)**
- **[Laporan Interaktif HTML](./LAPORAN_PEMANTAUAN_TERAPI_OBAT_SUNARTI.html)**
- **[Lembar Kerja CPPT Lengkap (Excel)](./CPPT_RANAP_LENGKAP.xlsx)**

## 📁 Direktori & Berkas Pendukung:
- `guideline_evidence/` : Tangkapan layar bukti guideline resmi (ADA, Lexicomp/FDA, EMA, KDIGO/PERKENI, PERHI/ACC-AHA).
- Berkas rekam medis PDF (asesmen awal, CPPT harian, laboratorium serial, radiologi, dan resume pemulangan).
